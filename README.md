ESTATES ARTHA - Luxury Real Estate Landing Page
A modern, mobile-responsive frontend built with HTML, CSS, and vanilla JavaScript, designed for a premium real estate agency.

Key Features:

3D Vertical Carousel: Smooth infinite-scrolling property cards with an interactive click-to-view details overlay.

Dynamic Split Layout: Clean desktop view (left text, right carousel) that perfectly adapts to mobile screens.

Google Sheets Backend: Connects seamlessly to Google Apps Script for instant lead capturing and data storage.

Automated Email System: Dispatches a rich HTML-formatted "Thank You" email to customers and a real-time lead alert to the admin.

Instant Database Cleanup: Features a smart onEdit script to automatically delete empty rows in the spreadsheet.
